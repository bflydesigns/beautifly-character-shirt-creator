# Prompt Framework

## Master brief fields

Include only relevant fields; write `None` only when omission could cause ambiguity.

- DESIGN TYPE: T-Shirt / Apparel Graphic
- CANVAS: Vertical 7:8
- ENTERTAINMENT SOURCE AND TITLE
- ARTWORK USAGE / RIGHTS-SAFE MODE
- CHARACTER SELECTION, ROLE, AND DESCRIPTION
- REFERENCE PHOTO IDENTITY ANCHORS AND USER-LOCKED FEATURES
- ART STYLE AND EXAGGERATION
- FACIAL EXPRESSION AND NATURAL FACIAL DETAIL
- BODY LANGUAGE / POSE
- COMPOSITION AND LAYER PLAN
- QUOTE / SAYING AND EXACT TEXT LOCK
- QUOTE PERSONALITY
- TYPOGRAPHY STYLE, CONSTRUCTION, AND EFFECTS
- COLOR PALETTE, including supplied hex values
- SUPPORTING ELEMENTS
- BACKGROUND
- PRINT-PRODUCTION DIRECTION
- VISUAL QUALITY AND CREATIVE INTENSITY
- CUSTOM CREATIVE DIRECTION

## Shared generation language

Create an isolated, premium commercial T-shirt illustration in a vertical 7:8 aspect ratio. Build a richly layered Photoshop-style composition with distinct back accents, story-supporting props, typography depth, a dominant character layer, strategic foreground lettering, and restrained foreground accents. Use purposeful overlap, scale, contour, dimensional lighting, refined shading, strong hierarchy, clean negative space, crisp edges, rich saturation, and a complete apparel-ready silhouette.

Render expressive, memorable character storytelling with believable anatomy. Push the selected emotion through the eyes, eyebrows, eyelids, cheeks, nose, mouth, jaw, head angle, hands, and posture. Integrate all facial details naturally.

When a reference photo is present, use it only as an identity and feature reference. Preserve recognizable facial structure, skin tone, hairstyle, hairline, age range, body type, and distinctive features, but redraw the complete subject from scratch as a premium semi-realistic editorial caricature with glossy airbrushed digital illustration. Translate the face, hair, hands, clothing, and body into one consistent illustrated treatment using crisp expressive contour lines, sculpted shading, controlled highlights, saturated color, and intentional caricature exaggeration. Maintain recognizable identity without maintaining photographic realism. Preserve pose, clothing, accessories, or expression exactly only when the user locks them.

Produce only isolated artwork—no shirt, model, hanger, mockup, room, presentation board, grid, or product scene. Keep every important limb, hairstyle, letter, and prop fully visible. Default to a pure white background unless true transparency is explicitly requested.

## Variation structure

For each of five prompts, specify:

- Variation title and creative thesis
- Character pose, expression, and crop
- Layer order and overlap
- Typography construction and placement
- Supporting props and story cues
- Color distribution
- Background treatment
- Elements deliberately changed from the other variations

## Negative prompt / quality control

No collage, contact sheet, grid, composite sheet, shirt mockup, model, hanger, room, duplicated character, duplicate props, stray letters, misspelled text, invented wording, unwanted logo, accidental branding, malformed hands, extra fingers, broken anatomy, cropped arms, cropped hair, cropped typography, cut-off props, flat clip-art styling, weak expression, pasted-on facial details, generic stock-vector appearance, muddy colors, excessive clutter, smoke, mist, fades to transparency, random paint splatter, heavy exterior shadow, distressed erosion, unnecessary halftones, photorealistic face, realistic studio portrait, photographic skin texture, visible pores, photo cutout, photobashing, face-swap appearance, pasted-on head, beauty-filter portrait, waxy 3D rendering, realistic fashion photography, or illustrated body with a photographic head.

## Commercial-safe substitution

When commercial-safe mode applies, replace protected specifics with an original character identity, transformed wardrobe, original setting cues, and new wording. Preserve only broad comedic premise, emotional energy, era, genre, or archetype. Do not claim that a prompt is legally cleared; recommend professional rights review when intended use carries material risk.
