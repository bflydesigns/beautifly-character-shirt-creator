# Beautifly Character Shirt Creator

An installable Beautifly Designs plugin for creating premium, layered, print-ready 7:8 character T-shirt artwork inspired by entertainment concepts and uploaded reference photographs.

## What it creates

- Five separate 7:8 T-shirt design variations
- Premium illustrated caricatures from uploaded reference photos
- Layer-conscious compositions for apparel production
- Coordinated dimensional typography and supporting elements
- Clean white-background or requested transparent-background artwork

The plugin is designed specifically for T-shirt artwork—not stickers, mugs, tumblers, posters, or social graphics.

## Install

Add this repository as a plugin marketplace source:

`https://github.com/bflydesigns/beautifly-character-shirt-creator`

Then open the Plugins directory, select the **Beautifly Designs** marketplace, and install **Beautifly Character Shirt Creator**. Start a new chat after installation.

## Example request

> Use the Beautifly Character Shirt Skill to turn my uploaded group photo into five separate layered 7:8 T-shirt designs. Preserve each person's recognizable identity while converting everyone into premium illustrated caricatures. Use the exact words “No Couple Is Perfect!” and a cream, metallic gold, and black palette. Create each variation as a separate image on a white background.
